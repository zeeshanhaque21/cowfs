## 6. State between reps

Not restorable, but harmless.
`g2()` appends one comment line to the corpus file each rep and never resets it (bench/gates.py:299-302).
`ensure_corpus` only checks HEAD, so a dirty tree persists across reps and across resumed runs.
In my scratch clone 3 reps left `git status` modified with 3 appended lines.
Drift is comment-only, grows by one line per rep, and every rep forces a real rebuild by the unique `time_ns` stamp, so it does not change the workload.
It is the same pattern as before the PR (not a regression).
