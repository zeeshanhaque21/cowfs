- Runs without g2 reps are unaffected (test_gates_without_g2_need_no_platform; old g1/g3 pair rc 0 with no platform key). No committed fixture or bench/out file carries g2 reps, so no committed data turns INVALID.
- Direction of the fallback is safe. For any native g2 median of at least the 3.0 s floor, the Linux 1.5x ratio allows at least 1.5 s added, which is more lenient than the macOS 1.0 s budget. A Mac run mislabelled Linux would therefore fail open. The PR does not default to Linux: missing or unknown platform is exit 3, and a bad `measured_on` value does not fall through to `platform`.
